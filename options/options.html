My Simple Tabs Workspace

Settings

Changes save as you make them and apply the next time the popup opens.

Settings file

Settings are backed up on their own, separately from workspaces, so you can carry a setup to another profile without touching the tabs there.

Workspaces

Save a backup

Writes every workspace, its tabs and its tab groups to a JSON file. Open windows are included as they were last saved.

Restore a backup

Restored workspaces arrive closed. Open one from the toolbar popup to bring its window back.

About the file

The format carries a version number, and unknown fields are kept as they are. A backup from an older release restores into a newer one, and a newer file is refused with a clear message rather than being read incorrectly.

A backup lists every page in every workspace. Treat it like your history.
